# AI Hub 110 — 어린이 보호구역 내 어린이 도로보행 위험행동 영상 데이터

CCTV로 찍은 위험행동 영상이다. 프레임마다 사람 상자가 있다.
첫 과제에는 쓰지 않는다. 다른 환경에서의 검증 데이터 후보다.

> [!note] 근거
> 이 페이지의 수치는 2026-11-16에 원본 폴더를 직접 읽어서 얻었다. `raw/`에 ingest한 문서는 없다.

## 1. 위치와 용량

경로: `/mnt/data1/downloads/교통데이터/110.어린이_보호구역_내_어린이_도로보행_위험행동_영상_데이터/01.데이터/`
용량: 667GB.

- `1.Training`만 있다. `2.Validation`은 없다.
- CCTV 분류(`1.CCTV`)만 받았다.

- 폴더 이름의 대소문자가 섞여 있다. `1.CCTV`와 `1.cctv`가 모두 있다.
- `이미지`는 프레임 jpg, `clip`은 영상 mp4다.

### 2.1 zip 안의 경로

| 종류 | 경로 |
|---|---|
| 라벨 | `<영상 이름>/<영상 이름>_<프레임 5자리>.xml` |
| 이미지 | `<영상 이름>/<영상 이름>_<프레임 5자리>.jpg` |
| 영상 | `<영상 이름>.mp4` |

- 영상 이름 예: `2020_12_02_10_31_driveway_walk_sun_A_04`. 날짜, 시각, 행동, 날씨, 구역, 번호 순서다.
- 영상 1개에 프레임 300장이 있다(라벨 기준).
- 각 zip 안에 영상마다 `<영상 이름>.zip`이 또 들어 있다. 이 안쪽 zip의 내용은 확인하지 않았다.
- 라벨과 이미지의 폴더 이름은 대소문자가 다르다. 라벨은 `..._sun_a_04`, 이미지는 `..._sun_A_04`다. 짝을 맞출 때 대소문자를 무시해야 한다.
- 라벨 zip에 `.lnk` 파일(Windows 바로가기) 35개가 섞여 있다. 쓰지 않는다.

## 3. 행동별로 받은 범위

라벨과 원천이 짝이 맞지 않는 행동이 있다.

| 행동 | 라벨 | 이미지 | 영상 |
|---|---|---|---|
| `driveway_walk` (차도 보행) | 있다 | 있다 | 있다 |
| `fall_down` (넘어짐) | 있다 (1~10) | 일부만 있다 (1, 2) | 있다 (1~10) |
| `jay_walk` (무단 횡단) | 있다 (1~4) | 없다 | 없다 |
| `fighting` (싸움) | 없다 | 있다 (1~8) | 일부만 있다 (8) |
| `ride_moto` (오토바이 탑승) | 없다 | 없다 | 일부만 있다 |

라벨과 이미지가 모두 있는 것은 `driveway_walk` 전체와 `fall_down` 1, 2뿐이다.

> `fighting`은 라벨이 없어서 이 프로젝트에는 영향이 없다.

## 5. 라벨 XML 형식

Pascal VOC 형식이다. 프레임마다 XML 1개다.

```xml
<annotation>
  <size><width>3840</width><height>2160</height><depth>3</depth></size>
  <object>
    <name>person</name>
    <bndbox><xmin>3131</xmin><ymin>1182</ymin><xmax>3341</xmax><ymax>1640</ymax></bndbox>
  </object>
  <object>
    <name>vehicle</name>
    <bndbox><xmin>0</xmin><ymin>692</ymin><xmax>274</xmax><ymax>1080</ymax></bndbox>
  </object>
</annotation>
```

- 이미지 크기가 라벨에 있다. 확인한 파일은 3840×2160이다.
- 확인한 클래스 이름은 `person`, `vehicle`, `license plate`다. 파일 1개에서 본 것이다. 전체 클래스 목록은 세지 않았다.
- XML의 `<filename>`은 믿을 수 없다. 실제 이름과 다른 값(`..._crosswalking_..._00001.txt`)이 들어 있다. 짝은 zip 안의 경로로 맞춘다.

## 6. 이 프로젝트에서의 쓰임

- 첫 과제의 학습에는 쓰지 않는다.
- 다른 환경(어린이 보호구역, 4K)에서 모델이 얼마나 버티는지 보는 검증 데이터 후보다. ([[dataset-split-plan]] 6절)
- [[aihub-101-cctv]]와 다른 점: 영상에서 연속으로 뽑은 프레임이라 서로 매우 비슷하다. 쓸 때는 프레임을 건너뛰어 뽑는다.
