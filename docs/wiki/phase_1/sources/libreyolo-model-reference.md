# LibreYOLO 공식 모델 목록

- 모델 계열별 지원 범위와 가중치 정보를 제공한다. [공식 모델 목록](https://www.libreyolo.com/docs/models)
- 1.8.0은 2026-11-15에 배포됐다. [PyPI 1.8.0](https://pypi.org/project/libreyolo/1.8.0/)
- 이전 설정의 최소 버전에도 YOLOv9 학습 예제가 있다. [PyPI 1.7.4](https://pypi.org/project/libreyolo/1.7.4/)
- 학습 가이드는 데이터 형식과 공통 인수를 설명한다. [학습 가이드](https://www.libreyolo.com/docs/train)
- 작업별 라벨과 YAML 규격을 설명한다. [데이터 형식](https://www.libreyolo.com/docs/reference/dataset-formats)
- 규격 요약은 [LibreYOLO 데이터셋 형식](../../phase_0/concepts/libreyolo-dataset-formats.md)에 있다.
- 실험 logger(MLflow 등)와 callbacks를 설명한다. [Experiment loggers](https://www.libreyolo.com/docs/train/loggers)
- MLflow 연동 정리는 [libreyolo-mlflow](../analyses/libreyolo-mlflow.md)에 있다.
